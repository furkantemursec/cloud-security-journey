# OverTheWire: Bandit Walkthrough Notes (Levels 18–22)

## Level 18 -> Level 19: Non-Interactive SSH Command Execution

* **Goal:** Read `readme` on a server whose `.bashrc` immediately terminates interactive login sessions (`Byebye !`).
* **Command Used:**
  * `ssh bandit18@bandit.labs.overthewire.org -p 2220 "cat readme"`
* **Key Takeaway:** Passing a command directly at the end of `ssh` executes it remotely without loading an interactive shell profile.

---

## Level 19 -> Level 20: SUID (`setuid`) Binary Privilege Escalation

* **Goal:** Use a `setuid` executable owned by `bandit20` to read `/etc/bandit_pass/bandit20`.
* **Command Used:**
  * `./bandit20-do cat /etc/bandit_pass/bandit20`
* **Key Takeaway:** Files with the `s` permission bit (`-rwsr-x---`) run with the file owner's privileges rather than the executing user's.

---

## Level 20 -> Level 21: Background Netcat Listener (`&`) & `./suconnect`

* **Goal:** Serve the `bandit20` password over a local TCP port and trigger `./suconnect` to receive the next password.
* **Commands Used:**
  * `cat /etc/bandit_pass/bandit20 | nc -l -p 5544 &`
  * `./suconnect 5544`
* **Key Takeaway:** Running a Netcat listener in the background (`&`) allows testing local TCP services from a single terminal session.

---

## Level 21 -> Level 22: Auditing Scheduled Cron Jobs (`/etc/cron.d/`)

* **Goal:** Inspect `/etc/cron.d/cronjob_bandit22` and read the target file written by the scheduled script.
* **Commands Used:**
  * `cat /etc/cron.d/cronjob_bandit22`
  * `cat /usr/bin/cronjob_bandit22.sh`
  * `cat /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv`
* **Key Takeaway:** Misconfigured cron scripts writing sensitive output to world-readable `/tmp` files expose credentials to local users.

---

## Level 22 -> Level 23: Reverse-Engineering Dynamic Bash Variables & `md5sum`

* **Goal:** Calculate the dynamic `/tmp/<md5>` filename generated by `/usr/bin/cronjob_bandit23.sh` for user `bandit23`.
* **Commands Used:**
  * `cat /usr/bin/cronjob_bandit23.sh`
  * `echo I am user bandit23 | md5sum | cut -d ' ' -f 1`
  * `cat /tmp/8ca319486bfbbc3663ea0fbe81326349`
* **Key Takeaway:** Reading shell scripts line by line (`whoami`, `md5sum`, `cut`) allows reproducing dynamic file paths deterministically.
